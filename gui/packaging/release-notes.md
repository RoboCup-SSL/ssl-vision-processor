This release is the **SSL Vision Processor GUI** only. It doesn't include `vision_processor`, which does the camera processing: [build that from source](https://github.com/RoboCup-SSL/ssl-vision-processor#readme).

- `.tar.gz`: the program with its user guide, for any 64-bit Linux. Start with the [quick start](https://github.com/RoboCup-SSL/ssl-vision-processor/blob/master/gui/README.md#quick-start).
- `.deb`: the same program for Ubuntu 24.04, which can also run it as a service.
- `SHA256SUMS`: check your download with `sha256sum --check --ignore-missing SHA256SUMS`.
